# Tecnología Medioambiental · Guía para aprobar

**Proyecto iniciado el 5 de noviembre de 2026.**

Guía no oficial de la UPCT para preparar la asignatura. Está dividida en varias páginas:

- `index.html`: portada con acceso a todas las secciones
- `empezar.html`, `t1.html` … `t7.html`: temario por temas
- `parcial-2024.html`, `problemas.html`, `autoevaluacion.html`, `banco.html`, `simulador.html`: práctica
- `formulario.html`, `glosario.html`, `plan.html`: consulta rápida

Los estilos y los datos están en `assets/`.

Web: https://helionacon-ui.github.io/Tecnolog-a-Medioambiental/
